# Security Policy

## Reporting a Vulnerability

We take the security of Nexusyn Engine seriously. If you discover a vulnerability,
please report it privately so we can address it before public disclosure.

**Email:** security@nexusyn.ai

Please include:
- A description of the issue and potential impact
- Steps to reproduce or a minimal proof of concept
- Affected versions or commit hashes

We will acknowledge your report within 48 hours and provide updates as we investigate.

## Scope

This policy applies to the open-source repository (`github.com/nexusyn/engine`).
For security issues regarding the hosted service, contact security@nexusyn.ai.
